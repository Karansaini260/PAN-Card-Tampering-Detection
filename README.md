# PAN Card Tampering Detection 🪪

Detects **tampering in PAN card images** using image processing and **OpenCV**,
with structural similarity (SSIM) comparison between original and scanned copies.

## ✨ Features
- Image pre-processing & contour detection
- Structural Similarity Index (SSIM) comparison
- Highlights tampered regions visually

## 🚀 Getting Started
```bash
pip install -r requirements.txt
jupyter notebook
```

## 🛠️ Built With
- Python · OpenCV · scikit-image · imutils
